# KeelStone

Weekly priority planner for 2026. Pick three keel stones — the work that keeps the week from drifting — then carve real time against them and close with a short review.

## Features

- **Keel** — name must-ship stones with a why and hour target
- **Carve** — log protected focus blocks against a stone
- **Review** — week score + freeform note
- **Capacity** — honest weekly deep-work hours and per-stone targets
- Offline persistence via DataStore
- Material 3 + dark mode

## Build

```bash
cd apps/2026-09-07-KeelStone
chmod +x gradlew
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

Package: `com.dailyapps.keelstone`
