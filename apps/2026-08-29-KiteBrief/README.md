# KiteBrief

A 2026 daily briefing app: set a morning intention, fly three commitments, then land the day with an evening shutdown ritual. Local-only, offline-first.

## Features
- Morning briefing with energy + intention
- Three daily commitments with done tracking
- Evening shutdown notes and landing score
- Wind map insights for the last 7 days

## Build
```bash
cd apps/2026-08-29-KiteBrief
chmod +x gradlew
./gradlew assembleDebug
```

Package: `com.dailyapps.kitebrief`
