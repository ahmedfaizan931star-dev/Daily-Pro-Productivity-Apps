# PebbleLane

Daily meeting-drain tracker with protected deep-work blocks and an evening close-out.

## Features
- Harbor dashboard: drain score, protected minutes, close-out status
- Meeting log with minutes and drain rating
- Protected blocks you can lock and complete
- Evening close-out journal

## Build
```
cd apps/2026-08-30-PebbleLane
chmod +x gradlew
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/`
