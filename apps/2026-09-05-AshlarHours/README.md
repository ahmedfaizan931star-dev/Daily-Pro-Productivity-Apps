# Ashlar Hours

A 2026 daily time-mason for people who plan work like architecture.

You treat each hour as a cut stone: **Deep work**, **Admin**, **People**, or **Recovery**. The day is a wall — load-bearing blocks plus open joints so the structure can breathe.

## Features

- **Mason board** — hours 07:00–20:00 as placeable stones
- **Kind chips** — Deep / Admin / People / Rest
- **Done marks** — tap the ring to complete a stone
- **Balance** — deep-work target vs placed hours, mix of kinds
- **Ritual templates** — Maker day, Manager day, Light day
- **DataStore persistence** — plan survives restarts
- Material 3, dark / light

## Build

```bash
cd apps/2026-09-05-AshlarHours
chmod +x gradlew
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/`

Package: `com.dailyapps.ashlarhours`
