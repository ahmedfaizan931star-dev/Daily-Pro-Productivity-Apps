# SableQuorum

A personal decision journal for 2026. Capture the choice, the options you considered, the expected outcome, then close the loop with a later review.

## Features
- Open decision board with urgency and domain tags
- Structured decision capture (options, criteria, confidence)
- Outcome review after the fact
- Insight stats: close rate, average confidence, domain mix

## Stack
Kotlin · Jetpack Compose · Material 3 · Room · ViewModel + StateFlow · Navigation Compose

## Build
```bash
cd apps/2026-09-04-SableQuorum
chmod +x gradlew
./gradlew assembleDebug
```

APK output: `app/build/outputs/apk/debug/`
