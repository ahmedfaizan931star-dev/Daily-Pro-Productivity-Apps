# LedgerMesa

Weekly envelope budget tracker for 2026. Assign cash to named envelopes, log spends, and see remaining runway.

## Screens
- Mesa: remaining budget and envelope heat
- Envelopes: create and fund weekly pots
- Log: record spends against an envelope
- Runway: week progress and overspend alerts

## Build
```
cd apps/2026-08-30-LedgerMesa
chmod +x gradlew
./gradlew assembleDebug
```
APK: `app/build/outputs/apk/debug/`
