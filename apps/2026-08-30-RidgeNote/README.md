# RidgeNote

A confidence-calibrated decision journal for 2026.

Log important choices with a confidence score, review outcomes later, and see whether you are overconfident or underconfident.

## Features
- Capture decisions with context, options, and confidence (0-100)
- Review and mark outcomes as hit / miss / mixed
- Calibration dashboard that compares predicted confidence vs hit rate
- Offline-first Room persistence, Material 3 dark/light theme

## Build
```
cd apps/2026-08-30-RidgeNote
chmod +x gradlew
./gradlew assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`
