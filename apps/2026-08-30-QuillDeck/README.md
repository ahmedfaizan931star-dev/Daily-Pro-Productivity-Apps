# QuillDeck

Offline spaced-repetition study app for professionals. Capture cards from books, meetings, and skills; review them with a simple SM-2-style interval so knowledge actually sticks.

## Features
- Due-today review queue with flip cards (again / good / easy)
- Multiple decks with local Room persistence
- Retention and streak metrics
- Material 3 light/dark theme

## Build
```bash
cd apps/2026-08-30-QuillDeck
chmod +x gradlew
./gradlew assembleDebug
```
APK: `app/build/outputs/apk/debug/`
