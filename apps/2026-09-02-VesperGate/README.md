# VesperGate

Evening closeout ritual for knowledge workers. Close open loops, park unfinished work, set a single morning intention, and leave the day behind.

## Features
- Tonight's gate: score the closeout and track ritual completion
- Open loops: capture unfinished threads with park / close actions
- Morning intention: one first-move for tomorrow
- Ledger: history of evenings with loop counts and notes

## Build
```bash
cd apps/2026-09-02-VesperGate
chmod +x gradlew
./gradlew assembleDebug
```

CI: `.github/workflows/build-vespergate.yml`
