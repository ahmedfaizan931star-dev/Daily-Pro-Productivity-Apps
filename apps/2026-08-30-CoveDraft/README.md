# CoveDraft

A 2026 shutdown-first planner. Park unfinished work so it leaves working memory, give incoming requests a real verdict, and close the day with one named win.

## Features
- Harbor dashboard of parked drafts, launch items, and verdicts
- Draft parking with optional launch-list promotion
- Decision log: Accept / Defer / Decline
- Evening close-out that can auto-park leftovers

## Build
cd apps/2026-08-30-CoveDraft && chmod +x gradlew && ./gradlew assembleDebug

Package: com.dailyapps.covedraft
