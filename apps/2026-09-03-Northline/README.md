# Northline

A 2026 daily-priority planner that keeps one north-star outcome in view and queues supporting work by impact and energy.

## Features
- Today: set the day's north-star outcome and work the ordered queue
- Queue: capture commitments with energy cost and leverage score
- Review: close the day, score alignment, and keep a weekly streak
- Insights: see which energy bands and friction tags drain the line

## Build
```
./gradlew assembleDebug
```

Package: `com.dailyapps.northline`
Min SDK 26 / Target SDK 35
Kotlin + Jetpack Compose + Material 3
