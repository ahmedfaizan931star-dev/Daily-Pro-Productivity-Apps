# HarborRite

Dock incoming work into berths, log voyages (focused sessions), and close the week with a rite.

HarborRite is a 2026 weekly productivity companion: one harbor for projects, time at sea, and a closing ritual so unfinished work does not drift.

## Features
- **Harbor** dashboard: weekly minutes, busiest berth, recent voyages
- **Berths**: named work lanes with an intent
- **Voyages**: timed focus sessions with tide intensity (1-5) and notes
- **Rites**: weekly closeout reflections per berth
- Offline Room persistence, Material 3 dark/light theme

## Build
```bash
cd apps/2026-08-31-HarborRite
chmod +x gradlew
./gradlew assembleDebug
```
