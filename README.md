# Daily Pro Productivity Apps

This repository automatically receives **one new pro-level productive Android app** every day, generated by Grok automation.

- **Tech stack**: Kotlin + Jetpack Compose + Material 3
- **Each app** lives in its own folder under `apps/`
- **APK builds** are handled by GitHub Actions

## Structure
```
apps/
  YYYY-MM-DD-AppName/
    app/
    build.gradle.kts
    settings.gradle.kts
    ...
.github/workflows/
  build-apk.yml
```

## How it works
1. Grok Automation runs daily
2. Generates a complete new Android project
3. Pushes all files to this repo
4. GitHub Actions builds the APK
5. APK appears as an artifact in the Actions run

## Download APKs
Go to the **Actions** tab → select the latest successful run → download the APK artifact.
